# ADR-0020: IPPanel Webservice SMS for Iran Production

## Status

Superseded by ADR-0056

## Date

2026-08-10; superseded 2026-09-09

## Provenance record

This identifier selected IPPanel Edge Webservice SMS while preserving Notification-owned exact
rendering, one-recipient requests, ambiguity-safe submission, authenticated recipient-level delivery
evidence, and local-only simulated adapters. ADR-0056 replaces only the provider-specific IPPanel
contract with the owner-selected SMS.ir contract. The retained cross-provider lifecycle and safety
invariants remain current through ADR-0006, ADR-0007, and ADR-0056.
