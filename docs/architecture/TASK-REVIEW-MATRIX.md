## Escalation rules

- **bounded-context-boundary** — Changing or creating a bounded context, independent deployable, or service boundary requires full architecture review.
- **security-authority** — Changing authentication, Authorization, MFA, tenant authority, trust, quota authority, secret authority, or admission architecture requires full review.
- **persistence-consistency-recovery** — Changing persistence ownership, consistency, durability, backup, restore, or recovery semantics requires full review.
- **platform-topology-technology** — Introducing, removing, or replacing platform topology, a control plane, or architecture-sensitive platform technology requires full review.
- **broad-or-uncertain** — Broad, cross-cutting, conflicting, or uncertain current-source scope requires full review.
- **privileged-agent-operations** — Changing AI/agent local write, process execution, administrator authority, or Ops MCP trust boundaries requires full architecture and security review.

Targeted review does not permit skipping executable evidence, current implementation inspection, or current diff review.
